# Security

Please report security problems privately through GitHub:
**Security → Report a vulnerability** on this repository. Don't open a public issue.

What's in scope: the app (`src/`), the update path (`src/update.rs`, `.github/workflows/release.yml`)
and how the driver is installed (`src/driver.rs`). Issues in the Virtual Display Driver itself
belong upstream at https://github.com/VirtualDrivers/Virtual-Display-Driver.
